# نموذج موقع الأستاذ الدكتور عبد الوهاب السيسي

موقع ثابت مستقل، عربي RTL وإنجليزي LTR. لا نماذج ولا قاعدة بيانات ولا تتبع. لم يُنشر الموقع خارجيًا.

## المعاينة
افتح index.html مباشرة للنسخة العربية أو en.html للإنجليزية. أو من هذا المجلد شغّل `python3 -m http.server 8000` وافتح http://localhost:8000. لا يحتاج تثبيت حزم أو عملية build. الروابط نسبية ومناسبة لمجلد فرعي في GitHub Pages.

## الملفات
- index.html / en.html: المحتوى والترجمة والروابط.
- assets/css/style.css: الألوان والتنسيق والتجاوب.
- assets/js/main.js: قائمة الهاتف والقسم النشط وتبديل اللغة ومعرض الصور.
- assets/images/: مكان الصور المعتمدة وتعليمات إدراجها.
- assets/fonts/: خطوط Tajawal وInter وPlus Jakarta Sans محلية مع تراخيصها.
- robots.txt: منع فهرسة النسخة التجريبية.

## تعديل المحتوى
عدّل HTML في النسختين، مع إبقاء معرفات الأقسام المتطابقة. روابط الحجز تحمل رسالة مشفرة لكل لغة. لتغيير الرسالة استخدم encodeURIComponent للنص أو quote في Python؛ لا تُدرج النص الخام في رابط URL. حافظ على rel="noopener noreferrer" للروابط الخارجية.

أُضيف بورتريه الدكتور ولقطة خريطة المبنى. اضغط الخريطة لفتح الموقع على Google Maps.

المقالات والفيديوهات والخدمات التفصيلية والأبحاث مواضع غير تفاعلية، وليست أزرارًا معطلة توحي بوظيفة متاحة. عند توفر المواد أضف عنوانًا معتمدًا وملخصًا وصورة ولغة ورابط مصدر. مساحة المنشورات تُحوّل إلى رابط «جميع المنشورات العلمية» فقط بعد توفير الرابط. لا توجد تضمينات فيديو ثقيلة.

## ما يحتاج اعتماد الدكتور قبل الإطلاق
- الاسم الإنجليزي Prof. Abdel Wahab El-Sisi.
- المسمى الأكاديمي وعبارة العمل بالتدريس حاليًا في جامعة الخرطوم.
- صورة البورتريه الشفافة والخدمات التفصيلية.
- مواعيد العيادة وروابط المقالات والفيديوهات والأبحاث وصور المشاركات.
- التهجئة الإنجليزية للمبنى والمركز وعبارة Lab Hair.
- الخريطة تشير إلى 119 التحرير الذي يتضمن آخر العنقود؛ يلزم اعتماد الدكتور لموقع العيادة داخل المبنى.

## النشر والفهرسة
بعد المراجعة ارفع محتويات المجلد كما هي إلى الاستضافة الثابتة. في GitHub Pages اختر المجلد/الفرع الصحيح أو ارفع هذا المحتوى إلى جذر المستودع. لا توجد عملية نشر تمت في هذه المهمة.

للإطلاق فقط: بدّل meta robots في الصفحتين من noindex,nofollow إلى index,follow واحذف منع الزحف في robots.txt (Allow: /). بعد معرفة الدومين أضف canonical وروابط hreflang مطلقة صحيحة وsitemap.xml بروابط النشر الفعلية. لم يُضف دومين وهمي. منع الفهرسة ليس حماية خصوصية؛ يفضل إبقاء أي معاينة مستضافة خاصة أثناء المراجعة.

## التحقق
جرى فحص بنية HTML والأقسام والروابط المحلية والخارجية وترميز رسائل واتساب وعدد H1 ووسوم اللغة واتجاهها ومنع الفهرسة وفحص صياغة JavaScript. لم تتوفر أداة معاينة المتصفح المعتمدة في بيئة Sites، لذلك لم يُجر فحص بصري فعلي على هاتف أو كمبيوتر؛ يلزم مراجعة العرض والقائمة والتركيز والتنقل على الأجهزة قبل الإطلاق. نقاط التجاوب: 1100px للقائمة و700px للتخطيط المتنقل. زر واتساب له مساحة منفصلة عند التذييل.
